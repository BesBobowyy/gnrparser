# GNR Parser
Лёгкая библиотека для парсинга файлов `.gnr` (Game Notation Record) и работы со структурированными данными игры.

## Возможности
- `gnrparser.read(data: str)` — разбирает текст в формате GNR и возвращает теги и список ходов.
- `gnrparser.analyze(data: dict)` — принимает разобранные данные и возвращает нормализованный результат с автозаполнением и дефолтными полями.

## Спецификация формата GNR (Версия 1)
Каждый файл GNR может содержать следующие поля:
- `[Version: ЦЕЛОЕ]` — версия формата.
- `[Game: СТРОКА]` — название игры.
- `[P<ЦЕЛОЕ>: СТРОКА]` — индекс и имя игрока. Поддерживается любое количество игроков (например: `[P1: Алиса]`, `[P2: Боб]`).
- `[Variation: СТРОКА]` — вариант игры.
- `[Termination: СТРОКА]` — как завершилась партия. Используйте `"null"`, если игра ещё идёт.
- `[Date: СТРОКА]` — дата игры (формат: `ДД.ММ.ГГГГ`).
- `[Field Size: ЦЕЛОЕ, ЦЕЛОЕ]` — ширина и высота игрового поля.
- `[Time Limit: СТРОКА]` — формат контроля времени. Примеры: `10+5`, `15`, либо `null` (без ограничения по времени).
- `[Organization: СТРОКА]` — место или организатор игры.
- `[Start Position: СТРОКА]` — закодированная начальная позиция (формат зависит от игры).
- `1. ХОДЫ 2. ХОДЫ 3. ...` — список ходов по номерам (разделены пробелами по каждому ходу).

## Установка
```pip install gnrparser```

## Использование
```
import gnrparser

raw_data = "...ваш GNR-контент..."
parsed = gnrparser.read(raw_data)
analyzed = gnrparser.analyze(parsed)
```
